## 🌟 Featured Project

<img src="https://raw.githubusercontent.com/Adarsh-patil-07/Adarsh-patil-07/main/PaySplitter-icon.png" width="88"/>

### PaySplitter
**Split smarter. Settle faster.**

*A cross-platform group-expense tracker (Web + Android) built to kill the "who owes who" spreadsheet chaos.*

</div>

<br>

- 🧮 **Settlement Engine** — a custom optimization algorithm that minimizes the number of transactions needed to settle group debts
- 💰 **Digital Pot** — automated equalization logic that keeps shared group funds balanced in real time
- 🔗 **Instant Invites** — share-code-based trip joining, zero account friction
- 📱 **True Cross-Platform** — one codebase powering both the web app and Android app, deployed on Netlify
